# Hirevora

AI-powered career assistant that tailors resumes, optimizes applications for ATS, creates cover letters, and helps job seekers manage their entire job search.

## MVP
- Mobile-first landing and application builder
- Job description + master resume intake
- ATS match and grounded resume tailoring (next)
- Cover letters and application tracking (next)
- Supabase auth/data and paid plans (next)

**Principle:** Hirevora must never invent qualifications, employment, education, certifications, or accomplishments.
